## About Plane View Collective

Plane View Collective brings together strategy, creative work, technology, and digital execution to help businesses strengthen their presence online.

The collective works across areas including:

- Brand Strategy
- Website Design & Development
- Digital Marketing
- Social Media & Content
- Digital Systems

The Plane View approach is built around a simple principle:

> **Clarity before creativity.**

The focus is not simply on creating visually appealing digital experiences, but on helping businesses communicate clearly, establish credibility, and create meaningful pathways for their audiences to take action.

## Technology Stack

The project repository contains configuration for the following technologies and tools.

### Astro

Astro is used as the primary web framework for the project.

### Tailwind CSS

Tailwind CSS is configured within the project for utility-based styling.

### Vite

Vite is configured as part of the project's development and build tooling.

### JavaScript

JavaScript is used for client-side functionality and interactive behaviour where required.

### HTML5

Semantic HTML provides the structural foundation for the website.

### CSS

CSS is used alongside the project's styling system for layout, presentation, and responsive behaviour.

### Git

Git is used for source-code version control and project history.

### Netlify

Netlify is used to deploy the website to its production environment.

## Project Structure

    planeview/
    ├── public/              # Static public assets
    ├── src/                 # Website source code
    ├── dist/                # Generated production build
    ├── astro.config.mjs     # Astro configuration
    ├── tailwind.config.js   # Tailwind CSS configuration
    ├── vite.config.js       # Vite configuration
    ├── tsconfig.json        # TypeScript configuration
    ├── netlify.toml         # Netlify deployment configuration
    ├── package.json         # Project metadata, scripts and dependencies
    ├── package-lock.json    # Locked dependency versions
    ├── node.txt             # Project Node.js information
    ├── git.txt              # Git-related project information
    └── README.md            # Project documentation

`node_modules/` is intentionally excluded from the documented project structure because it contains installed dependencies generated from the project's package files.
