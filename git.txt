1. Most explicit & safest (recommended)
From your current branch (let's say you're on my-work or feature/cool-thing):
Bash# Make sure everything is committed
git status

# Push to main
git push origin HEAD:main

# Push to develop
git push origin HEAD:develop

# Push to a specific feature branch
git push origin HEAD:feature/payment-redesign

# Push to a fix/hotfix branch
git push origin HEAD:fix/security-alert-2026

# Push to another one...
git push origin HEAD:fix/bug-123-login-crash

HEAD: means “whatever commit I'm currently on”
You can replace HEAD with a commit hash, tag, or branch name if needed
Each push is independent → you see immediately if any fails (rejected, non-fast-forward, etc.)
